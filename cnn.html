CNN
Convolutional Neural Network

ใช้ filter เลื่อนกวาดภาพ (convolution) เพื่อจับลวดลายเชิงพื้นที่ เหมาะกับข้อมูลภาพ

1หลักการทำงาน

Convolutional Neural Network ใช้ filter (kernel) เล็กๆ เลื่อนกวาดไปทั่วภาพ (convolution) เพื่อจับลวดลายเชิงพื้นที่ เช่น ขอบภาพ (edge), พื้นผิว จากนั้นค่อยๆ รวมเป็นลวดลายที่ซับซ้อนขึ้นในชั้นลึกๆ ถัดไป เหมาะกับข้อมูลภาพเป็นพิเศษ

วาดภาพ 8×8 พิกเซลด้านล่าง แล้วเลือก kernel เพื่อดูผลลัพธ์ของการทำ convolution แบบ real-time

2ลองเล่นได้เลย

คลิกหรือลากเมาส์บนภาพซ้ายเพื่อวาด/ลบพิกเซล ผลลัพธ์ convolution จะแสดงทางขวา
ตัวกรองขนาด 3×3 ที่ใช้เลื่อนกวาดภาพ แต่ละแบบจับลวดลายต่างกัน
ระยะการเลื่อน kernel ในแต่ละก้าว — stride สูงทำให้ output เล็กลง (ลด resolution) แต่คำนวณเร็วขึ้น
วาดภาพแล้วเลือก kernel เพื่อดูผล convolution

3Parameter Tuning

Parameterผลต่อโมเดล
kernel / filterค่าตัวเลขใน kernel กำหนดว่าจะจับลวดลายแบบไหน (ขอบ, ความคม, เบลอ) ในการเทรนจริง ค่าเหล่านี้ถูกเรียนรู้เองจากข้อมูล ไม่ได้กำหนดตายตัว
strideระยะก้าวการเลื่อน kernel stride=1 ได้ output ละเอียด stride=2 ได้ output เล็กลงครึ่งหนึ่ง ประมวลผลเร็วขึ้นแต่รายละเอียดหายไปบ้าง
paddingการเติมขอบภาพด้วยค่า 0 เพื่อรักษาขนาด output ให้เท่าภาพต้นฉบับ (ไม่ได้เปิดใช้ในตัวอย่างนี้)
n_filters / channelsจำนวน kernel ที่ใช้ในแต่ละชั้น ยิ่งมากยิ่งจับลวดลายได้หลากหลายขึ้น แต่โมเดลใหญ่ขึ้นตาม
