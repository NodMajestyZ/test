Reinforcement · #12

Reinforcement Learning
การเรียนรู้แบบเสริมกำลัง

Agent เรียนรู้ policy การกระทำที่เพิ่ม reward สะสมสูงสุด ผ่านการลองผิดลองถูกกับสภาพแวดล้อม (ตัวอย่างนี้ใช้ Q-Learning)

1หลักการทำงาน

Reinforcement Learning ให้ agent เรียนรู้ผ่านการลองผิดลองถูกในสภาพแวดล้อม (environment) โดยรับ reward เมื่อทำสิ่งที่ดี และเรียนรู้ policy (นโยบายการกระทำ) ที่เพิ่ม reward สะสมในระยะยาวให้มากที่สุด ตัวอย่างนี้ใช้อัลกอริทึม Q-Learning

Agent (จุดสีเขียว) ต้องเรียนรู้เส้นทางไปยังเป้าหมาย (⭐) โดยหลบสิ่งกีดขวาง (✕) กด Train เพื่อรันหลาย episode แล้วดู policy ที่ได้

2ลองเล่นได้เลย

คลิกช่องในกริดเพื่อวาง/ลบสิ่งกีดขวาง (✕) แล้วกด Train เพื่อให้ agent เรียนรู้เส้นทาง
อัตราการอัปเดตค่า Q — สูงเรียนรู้เร็วแต่ไม่เสถียร ต่ำเรียนรู้ช้าแต่มั่นคง
ให้ความสำคัญกับ reward ในอนาคตแค่ไหน — ใกล้ 1 มองการณ์ไกล ใกล้ 0 สนใจแค่ reward ทันที
โอกาสที่ agent จะ "สำรวจ" (สุ่มเดิน) แทนที่จะเลือกทางที่ดีที่สุดที่รู้อยู่แล้ว (exploitation)
กด Train เพื่อเริ่มให้ agent เรียนรู้

3Parameter Tuning

Parameterผลต่อโมเดล
alpha (learning rate)อัตราการอัปเดตค่า Q ต่อการเรียนรู้แต่ละครั้ง สูงไปอาจแกว่งไม่ลู่เข้า ต่ำไปเรียนรู้ช้า
gamma (discount factor)น้ำหนักของ reward ในอนาคตเทียบกับปัจจุบัน ใกล้ 1 ทำให้ agent วางแผนระยะยาว ใกล้ 0 ทำให้ agent โลภสั้นๆ
epsilon (exploration rate)ควบคุมสมดุลระหว่าง explore (ลองทางใหม่) กับ exploit (ใช้ทางที่รู้ว่าดี) — epsilon สูงช่วง early training ให้สำรวจเยอะ แล้วค่อยลดลง
episodesจำนวนรอบที่ agent ได้ลองเดินตั้งแต่ต้นจนจบ (ถึงเป้าหมายหรือหมดเวลา) ยิ่งมากยิ่งมีโอกาสเรียนรู้ policy ที่ดี
