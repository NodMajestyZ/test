LSTM
Long Short-Term Memory

โครงข่ายสำหรับข้อมูลลำดับ ใช้ gate ควบคุมว่าจะจำหรือลืมข้อมูลระยะยาวแค่ไหน

1หลักการทำงาน

LSTM (Long Short-Term Memory) เป็นโครงข่ายประสาทเทียมสำหรับข้อมูลลำดับ (sequence/time series) มี "cell state" ที่ทำหน้าที่เหมือนความจำระยะยาว ควบคุมด้วย 3 gate หลัก: Forget Gate (ลืมข้อมูลเก่า), Input Gate (รับข้อมูลใหม่), Output Gate (ส่งออกผลลัพธ์) ทำให้จำบริบทระยะยาวได้ดีกว่า RNN ธรรมดา

หมายเหตุ: ตัวอย่างนี้เป็นภาพจำลองแบบง่าย (illustrative) ให้เห็นว่า gate แต่ละตัวมีผลต่อ cell state อย่างไร ไม่ใช่โมเดล LSTM ที่เทรนจริง

2ลองเล่นได้เลย

คลิกแท่งในลำดับ input ด้านล่างเพื่อสลับค่าขึ้น/ลง แล้วปรับ gate เพื่อดู cell state เปลี่ยนแปลงทีละ step
ควบคุมว่าจะ "ลืม" ความจำเดิมมากแค่ไหน — ค่าน้อยลืมเยอะ ค่าเยอะจำนาน
ควบคุมว่าจะรับข้อมูลใหม่เข้ามาผสมกับความจำมากแค่ไหน
ควบคุมว่าจะส่งค่าจาก cell state ออกมาเป็น output มากแค่ไหน
ปรับ gate แล้วกด "รันทั้งลำดับ"

3Parameter Tuning

Parameterผลต่อโมเดล
forget_gateค่าใกล้ 1 = จำ cell state เดิมเกือบทั้งหมด (เหมาะกับ pattern ระยะยาว) ค่าใกล้ 0 = ลืมเกือบหมดทุก step
input_gateค่าใกล้ 1 = รับอิทธิพลจาก input ใหม่เต็มที่ ค่าใกล้ 0 = แทบไม่รับข้อมูลใหม่เข้ามาปรับความจำ
output_gateควบคุมว่า cell state จะถูกส่งออกมาเป็นค่า hidden state / prediction มากแค่ไหนใน step นั้น
sequence_lengthความยาวของลำดับที่ป้อนเข้าโมเดล ยิ่งยาวยิ่งทดสอบความสามารถในการจำบริบทระยะยาวของ LSTM
ตัวอย่างนี้เป็นภาพจำลองอย่างง่ายเพื่อความเข้าใจ ไม่ใช่โมเดลที่เทรนจากข้อมูลจริง
