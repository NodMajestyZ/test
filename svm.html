1หลักการทำงาน

Support Vector Machine หาเส้นแบ่ง (hyperplane) ที่มีระยะห่าง (margin) จากจุดข้อมูลที่ใกล้ที่สุดของแต่ละคลาสมากที่สุด เทรนด้วยการลด Hinge Loss พร้อม regularization ที่ควบคุมด้วยค่า C

เพิ่มจุดสองคลาส แล้วกด Train เพื่อดูเส้นแบ่งและแถบ margin สองข้าง

2ลองเล่นได้เลย

เลือกคลาส คลิกเพิ่มจุด แล้วกด Train
คลาส A คลาส B hyperplane / margin
C สูง → เน้นจำแนกถูกทุกจุด (margin แคบ เสี่ยง overfit) / C ต่ำ → ยอมให้ผิดบ้างเพื่อ margin กว้างขึ้น (generalize ดีขึ้น)
อัตราการอัปเดตน้ำหนักระหว่างเทรน

3Parameter Tuning

Parameterผลต่อโมเดล
Cควบคุม trade-off ระหว่างการจำแนกถูกทุกจุด กับความกว้างของ margin — C สูงลด margin แต่ลด training error, C ต่ำเพิ่ม margin แต่ยอมรับ error มากขึ้น
kernelในตัวอย่างนี้ใช้ linear kernel (เส้นตรง) เท่านั้น ในงานจริงมี RBF/polynomial kernel สำหรับข้อมูลที่แบ่งด้วยเส้นตรงไม่ได้
learning_rateก้าวการอัปเดตน้ำหนักระหว่าง gradient descent บน hinge loss
