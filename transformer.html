Transformer
โครงข่ายที่ใช้ Self-Attention

ใช้กลไก Attention ให้ทุกคำในประโยคมองเห็นกันพร้อมกัน จับความสัมพันธ์ระยะไกลได้ดี พื้นฐานของ LLM

1หลักการทำงาน

Transformer ใช้กลไก Self-Attention ให้แต่ละคำ (token) ในประโยคมองเห็นและให้น้ำหนักความสำคัญกับคำอื่นๆ ทุกคำพร้อมกัน (ไม่ต้องอ่านทีละคำแบบ RNN/LSTM) ทำให้จับความสัมพันธ์ระยะไกลในประโยคได้ดี และเป็นสถาปัตยกรรมพื้นฐานของ LLM อย่าง GPT/Claude

พิมพ์ประโยคสั้นๆ แล้วคลิกคำเพื่อดู attention weight ว่าคำนั้น "ให้ความสนใจ" กับคำอื่นในประโยคมากแค่ไหน

2ลองเล่นได้เลย

คลิกคำใดคำหนึ่งเพื่อดู attention weight (เส้นหนา = ให้ความสนใจสูง) เป็นการจำลองแบบง่ายจาก embedding สุ่ม
ควบคุมความ "คมชัด" ของ attention — ต่ำ = โฟกัสแคบที่คำเดียวชัดเจน / สูง = กระจายความสนใจเท่าๆ กันหลายคำ
คลิกคำในประโยคเพื่อดู attention

3Parameter Tuning

Parameterผลต่อโมเดล
temperature (ใน softmax)ควบคุมความคมชัดของการกระจาย attention — ต่ำทำให้โมเดลโฟกัสเข้มที่ token สำคัญไม่กี่ตัว สูงทำให้กระจายน้ำหนักไปหลาย token มากขึ้น
n_heads (multi-head)จำนวน attention head ที่ทำงานคู่ขนาน แต่ละ head เรียนรู้มองความสัมพันธ์คนละมุม แล้วรวมผลลัพธ์ (ตัวอย่างนี้จำลองแค่ 1 head)
embedding_dimขนาดเวกเตอร์ที่ใช้แทนแต่ละคำ มิติสูงเก็บข้อมูลความหมายได้ละเอียดขึ้นแต่คำนวณหนักขึ้น
ตัวอย่างนี้จำลอง attention จาก embedding สุ่ม (deterministic) เพื่อความเข้าใจแนวคิด ไม่ใช่โมเดลที่เทรนจากข้อมูลภาษาจริง
