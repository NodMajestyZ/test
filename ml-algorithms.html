Machine Learning Algorithms

แผนภูมิจัดหมวดหมู่อัลกอริทึม ML ที่พบบ่อย แบ่งตามลักษณะการเรียนรู้ — จากข้อมูลที่มีคำตอบ (Supervised) ไปจนถึงข้อมูลที่ไม่มีคำตอบ (Unsupervised) เครือข่ายเชิงลึก (Deep Learning) และการเรียนรู้จากการลองผิดลองถูก (Reinforcement)

◆ Machine Learning
Supervised
มีคำตอบให้เรียน
เทรนจากข้อมูลที่มี label กำกับไว้แล้ว
01Linear Regression
ทำนายค่าตัวเลขต่อเนื่อง ด้วยเส้นตรงที่ fit ข้อมูลได้ดีที่สุด
02Logistic Regression
จำแนกประเภท (classification) โดยแปลงผลลัพธ์เป็นความน่าจะเป็น
03KNN
ทำนายจากเพื่อนบ้านที่ใกล้ที่สุด k ตัว ไม่มีขั้นตอนเทรนโมเดลจริงจัง
04Decision Tree
แตกกิ่งตัดสินใจตามเงื่อนไขของฟีเจอร์ทีละขั้น
05Random Forest
รวมพลัง Decision Tree หลายต้นเข้าด้วยกัน ลด overfitting
06SVM
หาเส้นแบ่ง (hyperplane) ที่มีระยะห่างจากข้อมูลแต่ละคลาสมากที่สุด
07MLP (Neural Network)
โครงข่ายประสาทเทียมแบบชั้นซ้อน เรียนรู้ pattern ที่ซับซ้อนได้
Unsupervised
ไม่มีคำตอบให้เรียน
หา pattern หรือกลุ่มจากข้อมูลดิบเอง
08K-Means
จัดกลุ่มข้อมูล (clustering) ออกเป็น k กลุ่มตามความใกล้เคียงกัน
Deep Learning
เครือข่ายเชิงลึก
สถาปัตยกรรม Neural Network เฉพาะทาง
09CNN
ถนัดข้อมูลภาพ ใช้ filter/convolution จับลวดลายเชิงพื้นที่
10LSTM
ถนัดข้อมูลลำดับ (sequence/time series) จำบริบทระยะยาวได้
11Transformer
ใช้กลไก attention มองความสัมพันธ์ทุกตำแหน่งพร้อมกัน พื้นฐานของ LLM
Reinforcement
เรียนจากรางวัล
เรียนรู้ผ่านการลองผิดลองถูกกับสภาพแวดล้อม
12Reinforcement Learning
Agent เรียนรู้นโยบาย (policy) การกระทำที่เพิ่ม reward สะสมสูงสุด
หมายเหตุการจัดหมวด: ปรับตำแหน่งของ K-Means มาไว้ใต้ Unsupervised Learning (แทน Supervised) เพราะเป็นอัลกอริทึม clustering ที่ไม่ใช้ label และแยก CNN / LSTM / Transformer ไว้เป็นกลุ่ม Deep Learning ต่างหาก เนื่องจากเป็นสถาปัตยกรรม Neural Network ที่ใช้งานได้หลายรูปแบบการเรียนรู้ ไม่ได้จำกัดอยู่แค่ Unsupervised
